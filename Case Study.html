Unit Root Testing

In order to provide the VAR models with stationary time series, we need to find out what order of integration they have. In order to do find this order of integration, we do unit root tests following the Pantula principle. We will be using the BootUR package to assist with this, as the boot_adf function will tailor the test statistic to match the structure of the provided data, making the critical values more reliable (is reliable the right word?). These tests will be applied to the non-differenced time series, as the differenced series are clearly (or are they? o.O) stationary already.
